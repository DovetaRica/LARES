# LARES

**Local AI Reasoning for Exceptional States**

**当前版本：v0.3.0，仅做只读观察与人工审核建议。**

新版提取了通用网页界面、分层记忆、时段/日报/周报流程、证据学习、模型对照和流式统计代码。家庭实体、原始事件、密钥、数据库、部署脚本和内部运维文档不进入公开包。

本版增加可选的报告复核、有界事实查询与空闲线索发现，支持人工任务跨重启恢复，并记录无正文的请求阶段指标。报告复核和空闲分析默认关闭，按需启用。见 [兼容性与验证范围](docs/release-v030.md)。

## 离线体验

推荐 Python 3.12，在独立虚拟环境中运行：

```sh
python -m pip install ".[app]"
python -m app.demo
lares-app --demo
```

浏览器打开 http://127.0.0.1:8080 。演示使用临时合成数据，不接 HA、不调用模型、不控制设备。退出后临时文件删除。AI 报告不会被伪造为演示结果。

旧版 `python -m home_ai demo` 保持兼容，无需应用扩展依赖。

## 使用边界

应用默认关闭联网和定时任务。它会读取专用工作目录的 `.env`，因此不要从生产目录启动，也不要连接已有生产数据库。真实接入须显式配置网络开关、HTTPS 远程端点和自己的实体白名单。真实模型语义效果与完整接入仍需按环境验证；公开旧版本数据库的增量迁移仅使用合成数据验证，不代表生产恢复演练。

来源项目的历史测试数字不代表公开提取版的结果；请以本版独立验证为准。已有预处理性能限制仍保留，不承诺 GPU 性能、识别准确率或生产吞吐。
