# Security policy

LARES is an experimental, shadow-only alpha. No stable production-support commitment is made; use the latest reviewed prerelease and read its limitations.

Do not post credentials, raw household logs or private configuration in public issues. For a suspected security vulnerability, use the repository's private vulnerability reporting option if it is available. If it is unavailable, open a minimal issue requesting a private contact channel without disclosing exploit details or sensitive data.

The maintainer will assess reports case by case; no response-time guarantee is promised. Never probe real household services or another user's systems to demonstrate a bug. Synthetic offline reproductions are preferred.
